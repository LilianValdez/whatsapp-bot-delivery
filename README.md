## Bot  de atendimento para lanchonete via WhatsApp
Este projeto é um **bot automatizado em python** para atendimento de pedidos via **WhatsApp Web**, voltado para lanchonetes com mais de uma unidade. Ele responde automaticamente mensagens de clientes, gera QR Code para pagamentos via Pix, registra históricos e permite agendamentos de pedidos.
## Funcionalidades
-Atendimento automático via WhatsApp Web
-Geração de QR Code para pagamentos via Pix
-Agendamento de pedidos
-Histórico de pedidos por clientes
-Separação por loja (LOJA 1 e LOJA 2)
-Armazenamento em CSV
## Requisitos
-Python 3.8+
-Google Chrome instalado
-ChromeDriver compatível com a versão do seu Chrome
